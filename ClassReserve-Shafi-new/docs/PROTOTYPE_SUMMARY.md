# Prototype Summary

This summary is derived from the Prototype Design assets in the repository. The UI appears to be a SaaS dashboard style layout with pages for dashboard, bookings, admin, and various components.

Key app flows to implement (from prototype):
- Search rooms by date/time/capacity
- Request booking with event details and file upload
- Approval workflow and role-based views (student/club/faculty/admin)
- Calendar view of approved bookings
- Admin room CRUD and maintenance blocking

Use this scaffold as the minimal codebase for implementing the above flows with PHP + MySQL and plain HTML/CSS/JS.
